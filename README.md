## 简介

**StarMap（星图）**，源StarMap 是一个面向红队与安全工程师的
本地化网络资产测绘平台
。
输入
公司名、域名、IP 、 ICP 备案号
，自动识别输入类型，编排对应的任务流：ICP 备案查询 → 根域名提取 → 子域名枚举 → 空间测绘平台补充 → 端口扫描 → 存活探测 → Web 爬虫 → 敏感信息识别，全程无需人工干预，任务结束直接产出
XLSX / Word 双格式报告
。

从一次测绘，到一片星海；从资产打点，到长期盯防，攻防所需，尽收图中。

## 功能展示

### 多入口资产收集

- **五类输入**：公司名 / 域名 / IP / ICP 备案 / 企业资产，自动识别
- **自动编排**：9 种任务流，从一次输入，到一份报告
- **自动流转**：任务完成后，爬虫 / 端口扫描 / 监测 / AI 分析 / 报告一键接力

### 多源数据聚合

- **空间测绘**：FOFA / Hunter / Quake 并发查询，ICP 备案 + ENScan 企业资产同步聚合
- **结果治理**：自动去重合并，来源可追溯
- **子域收集**：Subfinder 被动枚举 + DNS 字典爆破，双保险

### 端口扫描与存活探测

- **双引擎**：Gogo / 原生 TCP，外部工具缺失自动回退
- **服务识别**：90+ 端口映射，高危端口自动评级
- **存活探测**：HTTPx 提取标题 / 技术栈 / Server / 最近存活时间

### Web 爬虫与敏感信息识别

- **双模式爬虫**：内嵌 Katana，标准 / 无头任选
- **深度提取**：API 端点 + 字典爆破 + 敏感信息识别
- **贴近实战**：代理池、自定义规则与字典，CDN 识别内置 100+ 指纹

### 统一资产库

- **全类型收纳**：域名 / IP / URL / APP / 小程序 / 公众号 / 微博 / 招聘 / 著作权
- **治理顺手**：星标、标签、备注、忽略，按公司 / 来源 / 类型聚合穿透

### 持续监测

- **全协议探测**：HTTP / TCP / ICMP / DNS + TLS 证书监控
- **变更检测**：宕机、恢复、篡改、到期等 15 种规则，分级告警
- **多渠道通知**：钉钉 / 飞书 / Webhook，变动第一时间发送

### AI 辅助分析

- **对话式研判**：任务、资产、爬虫结果随问随答
- **灵活接入**：OpenAI / Anthropic 

### 报告交付

- **双格式**：XLSX  + Word 文档
- **可定制**：主题与模板自定义，汇报归档一键输出

### 星图 · 企业数字宇宙

- **全景可视化**：中心企业是恒星，域名 / IP / 应用 / 证书等资产化作环绕行星，关联测绘
- **关联成网**：资产归属、资产间关联全部连线呈现，AI 挖掘的潜在关联资产经人工二次复核后并入图谱
- **大屏展示**：全屏沉浸、镜头飞行聚焦、自动旋转巡航，汇报演示与指挥大屏直接可用
- **实时同步**：与资产库联动，图谱随任务自动更新，态势常看常更新

### 企业银河 · 全局星空总览

- **态势纵览**：每家企业一颗发光星辰铺满银河，资产规模越大星光越亮，全局分布一眼纵览
- **多维定位**：企业名 / 备案号 / 域名 / 任务名模糊搜索
- **巡航模式**：随机轮播聚光企业，自动巡航海量资产，支持手动操作查看
- **主题适配**：浅色银河 / 深空夜景双主题适配不同大屏环境，点击星辰直达单企业星图

## 快速开始

### 最简使用

Release 中下载与操作系统对应的二进制文件，放到任意目录直接运行。

```text
./starmap
```

浏览器访问：

```text
http://localhost:8080
```

> PS: 单文件即开即用。首次启动自动在同级目录生成 `configs/`、`data/`、`reports/`，并在终端打印管理员账号密码（默认用户名 `admin`，登录后请立即修改）。

### 应用场景速查

| 场景               | 说明                                                   | 任务选项                                                     |
| ------------------ | ------------------------------------------------------ | ------------------------------------------------------------ |
| **红队外网打点**   | 一条公司名打通备案 → 根域 → 子域 → 测绘补充 → 存活探测 | `任务管理 → 新建任务 → 公司名 → 勾选 DNS爆破 / 端口扫描 / 自动爬虫 / 报告` |
| **企业关联深挖**   | APP / 小程序 / 公众号 / 微博 / 招聘 / 著作权一次拿全   | `任务管理 → 新建任务 → ENScan → 配置企业数据源凭证`          |
| **已知域名摸排**   | 被动枚举加字典爆破，测绘平台兜底补漏                   | `任务管理 → 新建任务 → 域名 / 批量域名`                      |
| **端口暴露面核查** | IP / 网段高速扫描，服务识别 + 高危端口评级             | `端口扫描 → 新建任务 → 目标填 IP / CIDR → 选择端口预设`      |
| **敏感信息挖掘**   | 批量爬取站点，提取 API 端点与敏感信息                  | `爬虫中心 → 新建任务 → 从资产任务 / 端口扫描导入 → 开启字典爆破与无头模式` |
| **核心资产盯防**   | 宕机、恢复、证书到期、页面篡改分级告警                 | `资产监测中心 → 导入监测目标 → 配置钉钉 / 飞书 / Webhook 通知` |
| **报告交付**       | 任务完成自动生成，数据与结论一并打包                   | `报告中心 → 下载报告`                                        |

### 配置说明

配置文件位于 `configs/config.yaml`，可以直接编辑 YAML，也可以在 Web 页面「系统设置」中维护。常用配置块：

| 配置块                       | 作用                                       |
| ---------------------------- | ------------------------------------------ |
| `server`                     | HTTP 端口、最大并发任务数                  |
| `icp` / `aiqicha` / `enscan` | ICP 备案与企业数据源凭证                   |
| `fofa` / `hunter` / `quake`  | 空间测绘平台 API Key 与查询规模            |
| `subfinder` / `brute`        | 子域枚举 Provider 与 DNS 爆破字典          |
| `gogo` / `httpx`             | 端口扫描与存活探测参数                     |
| `crawler`                    | 爬虫深度、并发、代理池、字典与敏感信息规则 |
| `monitor`                    | 监测探测类型、TLS 检查与通知渠道           |
| `agent`                      | AI Agent、模型 Provider 与自动触发配置     |
| `scheduler`                  | 资产 / 爬虫 / 端口扫描三套独立并发池上限   |

### 输出文件

```text
configs/    运行期配置（config.yaml、gogo.yaml、指纹、字典、提取规则）
data/       SQLite 数据库（统一资产库、任务、日志）
reports/    XLSX / Word 报告输出
templates/  Word 报告模板
```

任务进度、日志、资产结果通过 WebSocket 实时推送至页面。**扫描可以随时终止**，已入库数据不丢失。
